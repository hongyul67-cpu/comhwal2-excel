# 엑셀 예제파일 만드는 스크립트 (v2)

`files/*.xlsx` 와 1급 저장소(`comhwal-excel`)의 `files/*.xlsx` 를 여기서 한 번에 굽습니다.
**파일을 손으로 고치지 말고 이 스크립트를 고쳐서 다시 구우세요.**

```bash
python build.py out          # 8개 전부 (out\ 에 _v2 이름으로)
python build.py out 2        # 2급만  /  python build.py out 1  → 1급만
python verify.py out         # ★ 검산 — 숨은 정답을 학생 칸에 넣어 채점이 전부 '맞음' 인지 확인
python deploy_files.py       # out/ → 두 저장소의 files/ 복사 + excel-files.html 다시 생성
```

## v2 의 짜임새

문제 하나는 `dict(q=, hint=, ans=, why=, fmt=, chkans=)` 한 줄이고, 이것 하나에서
**문제 줄 · 숨은 정답(AB열) · 채점 수식 · 정답·해설 줄** 이 한꺼번에 만들어집니다.

- `ans` — 학생에게 보여 줄 모범답안(글자). 정답 시트에 그대로 나옵니다.
- `chkans` — 채점용으로만 쓰는 **같은 값을 내는 다른 수식**. 배열 수식처럼
  그냥 넣으면 `#VALUE!` 가 나는 것을 SUMPRODUCT 로 바꿔 둘 때 씁니다. 없으면 `ans` 를 씁니다.
- 채점 칸 : `=IF(NOT(ISFORMULA(답칸)),"↖ 0 지우고 수식", IF(값이 같으면,"✔ 맞음","✘ 다시"))`
  → 숫자를 손으로 적으면 맞음이 안 나오고, 수식이 달라도 **결과값이 같으면 맞음**입니다.
- 노란 칸에는 `0` 을 넣어 둡니다(`ph()`). "이 0 을 지우고 수식을 넣으라" 는 표시입니다.
- 문제 왼쪽 A열에 `12 ▶F52` 처럼 **번호와 넣을 칸 주소**가 같이 나옵니다.
- 채점 기준은 AB열부터 숨겨 둡니다(`hide_helpers`).

## 걸렸던 것 (다시 밟지 말 것)

1. **설명 글이 `=` 로 시작하면 파일이 통째로 깨집니다.** openpyxl 이 수식으로 저장해 버립니다.
   `astext()` 로 글자임을 못박습니다 — `put`·`title`·`note`·`howto_sheet` 안에는 이미 들어 있습니다.
2. **2007 이후에 생긴 함수는 `_xlfn.` 을 붙여야** 합니다(`fx()`). 안 붙이면 열었을 때 전부 `#NAME?`.
   대상 : ISFORMULA · RANK.EQ · STDEV.S · DAYS · IFS · CONCAT · MAXIFS · SWITCH 등.
   화면에는 `_xlfn.` 이 보이지 않습니다.
3. 표시 형식에 한글 색 이름 `[빨강]` 을 쓰면 엑셀이 파일을 못 엽니다 → `[Red]` (화면에는 [빨강]으로 보임).
4. 시트 이름에 가운뎃점(`·`) 을 넣으면 수식에서 `'따옴표'` 가 필요해 번거롭습니다 → `DB조건` 처럼 붙여 씁니다.
5. 이 PC(학교 PC 포함) 엑셀은 **배열 수식에 Ctrl+Shift+Enter 가 필요한 버전**입니다.
   그냥 Enter 면 `#VALUE!` — 파일 안내문·따라하기에 그렇게 적어 두었습니다.
6. 답 칸 너비가 좁으면 큰 숫자가 `########` 로 보입니다. 합계를 묻는 문제가 있는 시트는 답 열을 15 이상으로.
7. 파일 이름은 **영문**으로 저장합니다(깃허브 Pages 주소 안전). 한글 이름은 `<a download="...">` 로 붙입니다.
